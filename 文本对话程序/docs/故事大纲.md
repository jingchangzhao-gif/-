# 1. 大纲

## 关于故事架构

整体发生地点与时间是林中小屋，季节是冬天，故事背景是听说这里由一座非常适合滑雪的雪山，正好家里有个亲戚在当那个雪山下的丛林里当护林员

1. 场景一： 房屋一楼
	1. 一楼大厅
		1. 钟表
		2. 壁炉(关键物品)
		3. 熊头和熊皮
		4. 三个沙发
		5. 滑雪板
		6. 潮湿的柴火
		7. 一台老式电视
	2. 一楼厨房
		1. 锈迹斑斑的菜刀
		2. 一些速食食品
		3. 打火机(关键物品)
		4. 一些厨房用品
	3. 一楼厕所
		1. 许久没有用过的浴缸
		2. 有裂痕的镜子
		3. 洗漱用品  
2. 场景二：地下室
	1. 一些切割动物用的器械
	2. 手术刀
	3. 枪柜
	4. 几台大冰箱
3. 场景三： 房屋二楼
	1. 二楼储藏室(门是上锁的)
		1. 一些象牙制品
		2. 鳄鱼皮
		3. 熊皮
		4. 狼皮
		5. 动物牙齿制作的项链
	2. 阳台
		1. 一套桌椅板凳
		2. 还冒着热气的红茶
	3. 二楼卧室
		1. 床
		2. 衣柜
		3. 一些换洗衣物，但是闻起来有点发霉了
		4. 吃剩下的饼干
		5. 一些关于野生动物的书籍

故事细节：

故事发生在一个暑假，乐乐因为从来没有见过自然的雪而且特别想要去雪山滑雪，从父母那里听说他的一个亲戚在一个雪山里当护林员，于是便有了这个行程

故事背景是关于盗猎者与护林员，乐乐去往了他的这个舅舅在雪山里建造的二层木屋，他在这里住了两天，二楼的一个房间和地下室舅舅一直不让他进去，所以他对那里产生了非常浓厚的兴趣，突然有一天他的舅舅在突然间看见了红色的信号弹后让乐乐一个人在家里先休息，而后独自前往了信号弹所在地。

而乐乐由于无聊开始详细探索舅舅跟他说不让他进去的禁地，在一番探索后，他打开了地下室的大门，地下室里弥漫着血腥味，一些巨大的切割工具上锈迹斑斑，而最显眼的就是几台冰箱，打开冰箱，满满的都是各种肉类，根据不同的种类进行分类，例如棕熊，老虎，狼等动物骨架和肉类，在最深处的工具台他找到了二楼储藏室的钥匙。

返回二楼，打开储藏室，各色动物头骨，一些稀有的动物制品都储藏在这里，熊皮地毯，狼头装饰，甚至还有狼牙制作的项链，在桌子上的笔记本上记录着关于这些动物制品的来源。

原来他的舅舅最开始确实是一名出色的护林员，他保护着自然环境，但是随着季节转凉他开始减少出去巡林的次数，寒冷的森林处处都是危险，而在一天早晨他听到了一声枪响，出于对于自己职业的操守他驱车前往了现场，而在枪响的地方是一名断了一头腿浑身布满伤痕的偷猎者和一只棕熊的尸体，他的伤口是在逃离棕熊时被树枝划破的，而在被棕熊咬掉一只腿后他开枪了，幸运的杀死了棕熊，出于人道主义舅舅救治了他但是没收了他的盗猎工具，并且将棕熊带回了他的房子，随着冬季降临大雪封山，而盗猎者也为他讲述了关于他为什么盗猎的原因，一头成年棕熊在一些富商那里价值60万以上，他的舅舅原本计划是在春天的适合就将盗猎者送往警局，但是得到这个消息后他沉默了，也许是心中的贪婪他与盗猎者达成了协议，由他给盗猎者他们提供动物尸体，而盗猎者则是通过他们自己的渠道将这些动物以合适的价格售出，毕竟对于他而言狩猎动物是要简单的多。
