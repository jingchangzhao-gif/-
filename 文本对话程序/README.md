# 林中小屋 · 雪山寒假

> 命令行文字冒险(纯 Python,零第三方依赖)

寒假,你应约来到雪山深处的护林员舅舅家中。
屋外大雪封山,屋内的炉火还没生起来。
舅舅反复叮嘱你:**二楼的储藏室和地下室,千万别进去。**
可越是不让进的地方,你越是想看看……

直到那天,一抹红色信号弹划破灰白的天际,舅舅匆匆出了门。
屋里只剩下你,和这座藏了许多门道的木屋。

## 快速开始

需要 **Python 3.8+**,无任何第三方依赖。

```bash
# Windows cmd
python game.py

# macOS / Linux
python3 game.py
```

> 💡 Windows cmd 里中文乱码时:先执行 `chcp 65001`,或改用 Windows Terminal / PyCharm 运行。

## 怎么玩

- 每到一个区域,会显示**区域描述 + 可交互对象菜单**;
- 输入菜单里的**数字**再回车执行,输入 `0` 退出;
- 拿取的东西会进**背包**,并可能从场景中消失;
- 有些门和抽屉需要**特定钥匙**才能打开——多查看、多拿取、多尝试;
- 场景与可选项会随剧情状态变化(比如点燃壁炉后,才会出现"浇灭炉火"的操作)。

更详细的场景与物品设定,见下方设计文档。
